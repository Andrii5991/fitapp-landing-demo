# FitApp Landing Blocks (Content + Design Direction)

## Core headline

Do workout  
Track progress  
Enhance your body

## Product description

FitApp is a workout logging app where users can track progress, set and achieve goals, plan training activity, and measure physical improvement over time.

## Design direction

- **Tone:** confident, energetic, progress-focused
- **Visual style:** dark athletic UI with warm accent highlights
- **Layout:** clear block sections with one key message per block
- **Media use:** each major block should include one relevant app screenshot

## Recommended page blocks

### 1) Hero block

- **Heading:** Do workout. Track progress. Enhance your body.
- **Subtext:** Log every workout, see your improvements, and train with a clear plan.
- **CTA:** Start free
- **Visual:** use `/screenshots/group-12.svg` as the primary hero visual/background.

### 2) Workout logging block

- **Heading:** Note every set in seconds
- **Subtext:** Record exercises, reps, weight, and rest times without slowing your session.
- **Visual:** use `/screenshots/iphone-14-1-1.svg`
- **Layout:** text on left, screenshot on right (desktop); stacked on mobile.

### 3) Progress tracking block

- **Heading:** See progress, not guesses
- **Subtext:** Track trends across weeks, compare performance, and spot personal records quickly.
- **Visual:** use `/screenshots/iphone-14-1-2.svg`
- **Layout:** screenshot left, text right to alternate rhythm.

### 4) Goals and planning block

- **Heading:** Set goals. Plan activity. Hit milestones.
- **Subtext:** Build routines, define targets, and monitor progress toward each goal.
- **Visual:** use `/screenshots/iphone-14-1.svg` or `/screenshots/imageProt.svg`
- **Layout:** centered copy with screenshot below for emphasis.

### 5) Final CTA block

- **Heading:** Ready to transform your training?
- **Subtext:** Start logging now and turn effort into measurable results.
- **CTA:** Get FitApp free
- **Visual:** use `/screenshots/group-1.svg` as a supporting graphic.

## Content notes

- Keep copy short and action-oriented.
- Use strong verbs: log, track, plan, improve, achieve.
- Prioritize measurable outcomes (consistency, PRs, goal completion).
- Ensure each block has one message and one screenshot focus.
